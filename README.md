# 75 Medium Tracker

A simple, no-install tracker for the 75 Medium challenge. Track five daily tasks across 75 days:

- Follow a healthy diet (one cheat meal per week)
- One 45-minute workout
- Drink a gallon of water
- Read 10 pages of any book
- Take a progress photo

Missing a day doesn't restart the challenge. Tap any past day on the grid to fix or fill it in.

## Use it

Open the live page: `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

Progress is saved in your own browser (localStorage). Each person who opens the link keeps separate progress, so you and your partner can each track your own challenge from the same link. Clearing browser data erases progress.

## Publish with GitHub Pages

1. Create a new repository on GitHub (public, so the link works for others).
2. Upload all the files in this folder (`index.html`, `manifest.json`, the `.png` icons, and `README.md`) (Add file > Upload files).
3. Go to Settings > Pages.
4. Under "Build and deployment", set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
5. After a minute, your link appears at the top of that page. Send it to your wife.

Tip: open the link on your phone and use "Add to Home Screen". The shortcut shows a gold "75" on a green background and opens full screen like an app.
